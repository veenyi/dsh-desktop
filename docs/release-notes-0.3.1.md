# DSH Desktop v0.3.1 发布说明

v0.3.1 修复两个升级相关问题：

## 修复
1. **跨版本升级后服务起不来的根因**：`~/.dsh/data/node_modules`（运行时依赖桥）在升级后仍指向旧版 runtime，
   导致新引擎加载不到 IM 渠道插件（ERR_MODULE_NOT_FOUND）。现在应用启动时会校验桥目标是否为当前运行时，
   失效自动重建（创建/保持/重建/悬空重试全部覆盖）。
2. **安装器升级识别**：已安装过 DSH Desktop（任意历史版本）时，安装器自动识别为**原位升级**——
   沿用原安装目录、跳过目录选择页；未安装过才是全新安装（可选择路径）。避免误装到多个位置。
3. latest.json 带 BOM 的解析告警已兼容（自动去 BOM）。

## 升级方式
- 已装 v0.3.0：设置 → 更新中心 → 下载并安装（自动校验 sha256 + 静默原位升级）
- 或手动运行 `dsh-desktop-0.3.1-setup.exe`（自动识别为升级）
