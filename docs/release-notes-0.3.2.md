# DSH Desktop v0.3.2 发布说明

修复两个问题：

## 1. 设置页 IM 渠道一直"加载中"
根因：设置窗口加载了错误的 preload 桥（`preload.js` 只暴露市场/欢迎页接口，
而设置页调用 `window.settings.*`），导致设置脚本报错中止——IM 渠道/更新中心/通用开关全部失效。
已修复为加载正确的 `shell-preload.js`。现在设置页可正常显示 IM 渠道（钉钉/飞书/Discord/QQ/企业微信）、
更新中心、开机自启等。

## 2. 附件全格式支持（不再只能发图片 / 不再"模型不接受图片"）
- **任意文件格式**：不再限制 PNG/JPG/WebP/GIF——PDF、Word、Excel、ZIP、代码文件等全部可拖拽/粘贴/上传
- **大小上限大幅放宽**：单文件 5MB → **200MB**，单条消息总量 100MB → **4GB**（无实际使用瓶颈）
- **图片直接发送**：不再出现"模型不支持图片输入"的拒绝——附件统一入库；
  不支持视觉的模型（如 DeepSeek）会把附件**文本化描述**（含文件名/类型/大小/本地路径），
  Agent 仍可通过文件工具读取附件内容继续工作；支持视觉的模型照常看图
- 消息里非图片附件显示为**文件块**（名称/类型/大小 + 打开链接），草稿栏显示 📄 图标
- 历史消息中的非图片附件可正常打开（不再破图）

## 升级方式
设置 → 更新中心 → 下载并安装（或运行 `dsh-desktop-0.3.2-setup.exe`，自动原位升级）。
