# DSH Desktop v0.3.3 发布说明

修复：使用其他模型（OpenAI 兼容 / vLLM 等）时出现
`400: the input prompt token len 478000 + max_new_tokens 1 > 262144` 上下文超限失败。

## 根因
1. 你的对话上下文涨到了 478K tokens，超过该模型 262144（256K）的上下文上限；
2. 该提供商的超限报错文案（"token len … > …"）不被 dsh 识别为"上下文超限"，
   导致自动压缩不触发，直接把 400 抛给你。

## 修复
1. **超限识别扩展**：新增对 vLLM / OpenAI 兼容常见文案的识别
   （`token len N > M`、`Requested tokens (N) exceed maximum`、`prompt is too long: N tokens > M` 等），
   命中后自动触发**上下文压缩并重试**，不再直接失败（已用实际报错文案验证命中，无关报错不会误判）。
2. **上下文窗口兜底**：自定义模型未上报上下文窗口时按 128K 保守值参与"80% 压力压缩"，
   让对话在涨爆前自动压缩，而不是等到 provider 拒收。
   —— 若你的模型窗口更大（如 256K），建议在 设置 → 模型 里把该模型的上下文窗口设为精确值
   （如 262144），压缩时机将最精准。
3. 说明：压缩会保留最近对话与目标摘要；历史细节会被折叠（这是任何长上下文方案的通用行为）。

## 升级方式
设置 → 更新中心 → 下载并安装（或运行 `dsh-desktop-0.3.3-setup.exe`，自动原位升级）。
