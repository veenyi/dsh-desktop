使用提示
· 对话输入框输入 / 可查看并调用已安装技能
· 输入 /goal 进入目标模式，长任务自动多轮推进
· 拖拽文件到窗口，路径自动复制到剪贴板
· 托盘图标常驻后台；右键托盘可设置开机自启 / 查看 IM 渠道状态
· 更新：设置 → 更新中心，从 GitHub Releases 检查并安装新版本
· 数据目录：~/.dsh（runtime / data / logs / appdata）
